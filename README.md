# 📦 Inventory Demand Prediction System

## Overview

This project predicts future inventory demand for electronic products using Machine Learning.

The application allows users to select a store, choose an electronic product, enter inventory details, and receive:

- Predicted Demand
- Demand Level
- Safety Stock
- Recommended Order Quantity

---

## Features

✔ Machine Learning Prediction

✔ Streamlit Web Application

✔ Electronics Products Only

✔ Automatic Product Prices

✔ Automatic Competitor Prices

✔ Holiday & Promotion Support

✔ Inventory Reorder Recommendation
